Reuse these existing transparent PNG assets for the Pro detail page. Prefer the `public/assets/michimachi` paths because they include the clean/display variants, and fall back to `public/assets/generated` only when matching the existing page implementation requires those names.

## Hero Town Strip

- `public/assets/michimachi/city-main-display.png` - large transparent city anchor for the main town strip.
- `public/assets/michimachi/city-harbor-display.png` - compact transparent waterfront block for side or background layering.
- `public/assets/michimachi/city-hill-clean.png` - clean transparent hill-town block for secondary skyline layering.
- `public/assets/michimachi/city-station.png` - transparent station block for route/progress accents.
- `public/assets/michimachi/workshop.png` - transparent workshop strip if the hero needs a broader foreground base.

## Feature Cards

- `public/assets/michimachi/construction-work.png` - transparent work-in-progress scene for analysis or guided-improvement cards.
- `public/assets/michimachi/construction-sign.png` - transparent sign object for alert, plan, or status cards.
- `public/assets/michimachi/equipment-desk.png` - transparent desk object for strategy/report cards.
- `public/assets/michimachi/equipment-lamp.png` - transparent lamp object for insight or focus cards.
- `public/assets/michimachi/equipment-shelf.png` - transparent shelf object for library, archive, or knowledge cards.
- `public/assets/michimachi/equipment-water.png` - small transparent object for compact supporting-card decoration.

## Pricing Cards

- `public/assets/michimachi/equipment-bag.png` - transparent equipment object suitable for the standard paid plan card.
- `public/assets/michimachi/equipment-shoes-clean.png` - cleaner transparent shoe asset for the entry or lightweight plan card.
