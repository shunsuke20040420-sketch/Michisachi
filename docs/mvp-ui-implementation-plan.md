# みちまち MVP UI 実装計画

## 目的

生成済みモック `public/mockups/michimachi-mvp-reference.png` を視覚契約として、React + Tailwind CSS で「みちまち MVP」の実アプリ画面を再現する。

## 参照画像

- `public/mockups/michimachi-mvp-reference.png`
- サイズ: 1638 x 960
- 画面構成:
  - 左: 「最初の街を作る」
  - 中央: 「今日のルート」
  - 右: 「街の成長」

## 生成・利用素材

image-to-image で生成した素材を `public/assets/mvp` に配置する。

- `mvp-town-assets-source.png`: クロマキー元素材
- `mvp-town-assets-transparent.png`: 背景透過済み素材シート
- `first-town-island.png`: 作成画面の小さな街
- `goal-house-mini.png`: 今日のルートの目標カード用ミニ家
- `growth-town-island.png`: 街の成長画面の大型街

UIアイコンは背景透過のSVGとして `lucide-react` を使い、LPで使っている緑・オレンジ・クリームのトーンに合わせる。

## 実装方針

- 既存LPビューアは壊さず、`#mvp` セクションとしてMVPアプリ画面を追加する。
- 既存の `#create-town` は維持しつつ、ナビに「MVP」を追加する。
- 実装はフルページ画像貼り付けではなく、ReactコンポーネントとCSSで再現する。
- スマホ3台の並列レイアウトをデスクトップで再現し、モバイルでは横スクロールまたは1カラムで崩れないようにする。
- アニメーションは静かなプレミアム感に寄せる。
  - スマホフレームの順次フェードアップ
  - ルートラインのグロー
  - CTAの軽いホバー
  - 街画像の微小な浮遊

- Worker 1: `src/components/MvpAppMockup.jsx`

- Worker 3: `src/App.jsx` と `src/styles/index.css` の統合部分のみ

## 受け入れ基準

- `#mvp` で3つのスマホ画面がリファレンスと同じ順序、密度、色、余白で表示される。
- 画像素材が透明PNGとして表示され、背景の四角が見えない。
- CTA、入力カード、ステータスカード、下部ナビがモックに近い。
- デスクトップで横幅に収まり、モバイルでも操作不能にならない。
- `npm run build` が成功する。
