# 公開文面・フィードバック・24時間確認手順

みちまちの初回公開で使う文面と、公開後24時間の確認手順。
公開URLと連絡先が未確定の場合は、角括弧のプレースホルダーを差し替えてから使う。

## 差し替え欄

- `[PUBLIC_URL]`: 公開URL
- `[PUBLIC_URL]/contact`: 先行登録・フィードバックフォーム
- `[CONTACT_METHOD]`: 追加連絡の返信先。例: XのDM、メールアドレス、Discordなど
- `[OWNER_NAME]`: 投稿者名またはチーム名

## フィードバック質問

フォームでは質問を増やしすぎず、以下3つに絞る。

1. みちまちを見て「自分でも使ってみたい」と思いましたか？理由もあれば教えてください。
2. どの画面や言葉で、何をするアプリか一番伝わりましたか？逆に迷った場所はありますか？
3. 目標・ルート・街・ログの表現で、もっと見たい機能や不安に感じた点はありますか？

メールアドレスを任意で受け取る場合は、フォーム上に次の説明を入れる。

いただいた連絡先は、みちまちの検証連絡・改善ヒアリング・公開案内のみに使用します。

## 公開後24時間の確認手順

### 公開直後

- `[PUBLIC_URL]` を通常ブラウザとシークレットウィンドウで開く
- スマホ実機でトップ、無料体験、共有フロー、Pro詳細を開く
- SNS投稿または共有メッセージ内のURLをタップして開けるか確認する
- OGPプレビューでタイトル、説明、画像が意図通り出るか確認する
- `/contact` またはDM導線が開けるか確認する
- 大きな表示崩れ、真っ白画面、戻れない導線があれば公開投稿を一時停止する

### 1時間後

- フォーム回答、DM、SNSコメント、引用、ブックマークを確認する
- 「何かわからなかった」「押せなかった」「怖い/怪しい」といった不安の言葉をそのまま記録する
- 端末やブラウザ依存の表示崩れが報告されていないか見る
- 反応数を手動で記録する
  - 投稿表示数
  - URLクリック数が見られる場合はクリック数
  - フォーム回答数
  - DM / コメント数
  - 「使ってみたい」反応数

### 6時間後

- 最初の反応を3分類する
  - すぐ直す: URL不備、フォーム不備、重大な表示崩れ、誤解を招く文言
  - 次回公開までに直す: 導線の迷い、説明不足、見たい機能の要望
  - まだ触らない: 好みの差、検証前に広げすぎる要望
- 公開文面を追加投稿する場合は、反応が多かった言葉を1つだけ反映する
- フォームの質問は原則増やさず、必要なら補足説明だけ調整する

### 24時間後

- 以下を1枚のメモにまとめる
  - 公開URL
  - 公開した場所
  - 反応数
  - フォーム回答数
  - 使ってみたい理由の代表例
  - 迷った場所の代表例
  - 次に直す3件
- 次の判断を決める
  - 限定共有を続ける
  - 文面や導線を直して再投稿する
  - フォーム/事前登録を整えて広める
  - まだ公開範囲を広げない

## 公開停止・差し戻しメモ

問題が出た場合は、利用しているデプロイ先で一時停止または直前デプロイへのロールバックを行う。
具体手順は公開先確定後にここへ追記する。

- デプロイ先: `[DEPLOY_PROVIDER]`
- 管理画面URL: `[DEPLOY_ADMIN_URL]`
- 一時停止手順: `[PAUSE_OR_ROLLBACK_STEPS]`
